# Memee - Local Meme Manager

A powerful Raycast extension for managing, searching, and quickly copying local memes and stickers. Perfect for organizing your personal meme collection for chat and social media interactions.

## Features

- � **Browse Local Memes**: View your meme collection in a beautiful grid layout
- 🔍 **Quick Search**: Find memes instantly by filename or tags
- 📋 **One-Click Copy**: Copy memes to clipboard with a single keystroke
- 🏷️ **Smart Organization**: Tag and categorize your memes by theme, emotion, or usage
- ⚡ **Lightning Fast**: Optimized performance for large meme collections
- 🎯 **Chat Ready**: Perfect for Discord, Slack, Telegram, and other messaging apps
- 💬 **Social Media**: Quickly share memes on Twitter, Reddit, and other platforms

## Installation

1. Open Raycast
2. Go to Extensions → Store
3. Search for "Memee - Local Meme Manager"
4. Click Install

Or install directly from the Raycast Store: [Memee Extension](https://www.raycast.com/memee)

## Usage

### Basic Usage

1. Launch the extension with the keyword "memee"
2. Browse your memes in the grid view
3. Use the search bar to filter memes
4. Press ⌘+C to copy selected meme to clipboard

### Advanced Features

- **Grid Size Adjustment**: Use the dropdown to change grid column count
- **File Actions**: Right-click or use Action Panel for additional options
- **Keyboard Navigation**: Use arrow keys to navigate, Enter to preview

## Development

This project is built with:

- **React**: Modern UI components
- **TypeScript**: Type-safe development
- **Raycast API**: Native Raycast integration
- **Node.js**: File system operations and meme processing

### Getting Started

```bash
# Clone the repository
git clone https://github.com/nolongerhesitate/memee.git
cd memee

# Install dependencies
npm install

# Start development
npm run dev
```
